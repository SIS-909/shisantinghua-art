```
[A 画风] [B 人物基础] [C 生产规范] [D 构图] [E 美学]
[1 内核] [2 发] [3 眼] [4 脸] [5 身] [6 衣] [7 标志物] [8 配色]
```

## A · 画风

```
Japanese visual novel character design, high-quality modern Japanese anime style,
refined 2D anime character illustration, clean delicate anime lineart,
soft watercolor-like rendering, subtle cel shading, soft diffuse lighting,
low contrast shadows, gentle atmospheric mood,
```

## B · 人物基础

```
youthful and delicate female character, natural Japanese anime facial proportions,
soft oval face, small delicate nose, small mouth, slightly narrow chin but not sharp,
expressive anime eyes with subtle emotion,
slender youthful body, narrow shoulders, slim limbs, small bust,
elegant but ordinary teenage girl proportions,
```

## C · 生产规范

```
designed as a production-ready visual novel character, strong and recognizable character silhouette,
clear hair silhouette, distinctive but practical hairstyle,
hair designed with clean large shapes suitable for 3D modeling and consistent perspective,
simplified readable clothing construction, limited number of recognizable accessories,
accessories placed in stable locations and easy to reproduce from multiple angles,
coherent front side and back silhouette, no excessive decorative complexity,
```

## D · 构图

```
full body standing character sprite, centered composition, neutral standing pose,
front-facing with a very slight natural angle, arms relaxed naturally at the sides,
full figure visible, feet visible, white background, no scenery, no props,
no dramatic action pose,
```

## E · 美学

```
soft youthful anime beauty, understated individuality,
character feels like a real girl rather than a fashion model,
visual novel aesthetic, emotionally expressive eyes,
quiet storytelling atmosphere, muted and harmonious colors,
```

## Z · 收尾

```
clean hair silhouette, simple clothing construction, recognizable accessories,
highly consistent 3D-model-friendly character design
```

## 附：三视图变体（只换 D 块）

出三视图时，把 D 块替换成下面这句，其余不动：

```
three-view character reference sheet, front view, side view and back view of the same character,
same pose family, consistent proportions across all three views, standing A-pose with arms slightly away from the body,
full figure visible, plain light background, no scenery
```

> 实测：三视图 → 立绘、立绘 → 三视图，**两个方向都能保持同一个人**。
