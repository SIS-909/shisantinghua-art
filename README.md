# shisantinghua-art

《十三庭花》立绘资产库 —— 提示词、母版图、生成结果。

**公开仓库的唯一目的：让境外图像模型能通过 `raw.githubusercontent.com` 拉到参考图。**

---

## 一、为什么需要这个仓库

图生图的参考图必须是**境外可达的公网 URL**。

| 地址 | 结果 |
|---|---|
| 官方临时图床（国内） | ❌ 上游模型拉不到 |
| Gitee raw | ❌ 403 |
| uguu.se | ⚠️ 可以，但 3 小时失效 |
| **GitHub raw（公开仓库）** | ✅ 稳定 |

所以：**参考图放这里，出图时引用 raw 链接。**

```
https://raw.githubusercontent.com/SIS-909/shisantinghua-art/main/refs/yuexin-sheet.png
```

## 三、三条硬规矩（违反一条，画风就散）

1. **发型必须是"大块"** —— 一块一块的形，能从三个角度画出来。不要细碎层次、飞散发丝。
2. **标志物必须落在稳定位置** —— 头顶、耳边、领口、手腕。换了衣服还在的地方。
3. **配色只能一个主色 + 一个色相偏移** —— 出现两组对撞色相，就跳出体系了。

## 四、生产流程

```
文字提示词
   ↓ 出 low 档（5 点）反复迭代，人工审图
定稿立绘  ←── 母版①
   ↓ 参考图 = 立绘，指令"保持人物一致性，生成便于建模的 a-pose 三视图"
三视图    ←── 母版②（建模用）
   ↓ 参考图 = 母版
演出服版本 / 表情差分（只换指定块，其余不动）
```

**关键：一致性靠"母版图"，不靠把提示词写得更细。**
提示词只能保证同一个**风格**，保证不了同一**个人**。

## 五、怎么往里推文件

这台机器没有 git，用 GitHub Contents API：

```
PUT https://api.github.com/repos/SIS-909/shisantinghua-art/contents/<path>
Authorization: Bearer <token>
{ "message": "...", "content": "<base64>", "sha": "<更新时必填>" }
```

## 六、规矩

1. 仓库必须**公开**（私有仓库 raw 需要 token，模型拉不到）
2. 文件名必须**英文**（中文路径会被百分号编码，模型可能取不到）
3. **绝不提交 API key / token**
